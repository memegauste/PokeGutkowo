# Frontend PokeGutkowo

React 19 + React Router 7 + Bootstrap 5, budowane przez Vite.

```sh
npm ci
npm start
npm test
npm run test:coverage
npm run build
```

Serwer developerski działa pod `http://127.0.0.1:3000` i przekazuje żądania API
do Django na `http://127.0.0.1:8000`. Pełna instrukcja konfiguracji znajduje się
w głównym [README](../README.md).
